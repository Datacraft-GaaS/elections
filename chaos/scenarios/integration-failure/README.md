# Integration Failure Scenarios (34 scenarios)
Role: Tests external adapter unavailability. Purpose: Prove EEL system does not lose signed events or M5 audit chain when any of 50+ integrations go offline. Functionality: each scenario targets a specific `adapter/` (telco-sms, telco-ussd, smtp, ipfs, printer, hsm-pkcs11, whatsapp, kra-itax, mpesa-daraja, iprs, nhif-shif, kbc-sftp, nssf, nrb, kps-kdf-unhcr, odpc-breach, nist-beacon, ifmis, datacite, ecourt, nllb, litellm, cbk, card-manufacturer, kebs-warranty, mck, pantone, ppdt, ivr, airline-cargo, printer-mes, mpesa-standby, satellite) or runs comprehensive integration loss. Configuration: chaos-testing namespace; PodChaos/NetworkChaos/HTTPChaos; fallback to outbox queue; HSM-signed recovery. Detection: `auditId`+`proofHash` preserved; `outbox` table drains on recovery.
