# Insider Risk Scenarios (16 scenarios)
Role: Models adversarial/privileged-abuse conditions. Purpose: Prove audit chain + HSM + falco + tetragon + deny.toml detect and block insider actions. Functionality: each scenario simulates a malicious insider action (adapter data manipulation, audit deletion, privilege escalation, duplicate injection, supply-chain adapter tamper, credential theft, vote manipulation, HSM key extraction, data exfiltration, session hijacking, gallery poisoning, outbox tampering, observer tampering, audit replay, double-spend, whitelist bypass). Configuration: chaos-testing namespace; HTTPChaos/NetworkChaos/StressChaos/IOChaos; detection via falco-rules (privilege escalation, unauthorized access, canary trigger) + wazuh (operator access, audit replay) + tetragon (kernel-level block) + deny.toml (supply-chain) + rust-toolchain.toml (compiler pinning).
