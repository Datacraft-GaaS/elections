# ModelCard Schema

Required sections for every eel AI model card:
- Purpose and scope
- Architecture and size (INT8/FP32, param count, disk size)
- Training data source (no PII, no biometric data descriptions)
- Eval metrics (accuracy, bias across demographic groups, adversarial robustness)
- Known failure modes and limitations
- Human-in-loop controls
- Kenyan jurisdiction hosting attestation
- DPIA reference ID
- Version history
- Rollback procedure
- IAB notification date
- CCB approval ID

Languages: English required; Swahili summary required.
