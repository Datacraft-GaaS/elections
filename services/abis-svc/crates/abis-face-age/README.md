# eel-abis-face-age

Age-invariant face matching for the EEL ABIS pipeline.

Provides age estimation, residual age-direction removal from embeddings,
and an age-progression stub for simulating growth.

## References

- Guo et al. (2019). A Survey on Age Estimation and Face Aging. ACM Computing Surveys.
- Wang et al. (2022). Age-Invariant Face Recognition via Partial Factor Pooling. CVPR.
