# eel-abis-face-quality

ISO/IEC 29794-5 face image quality for the EEL ABIS pipeline.

Metrics: sharpness (Laplacian variance), resolution (interocular distance),
pose (yaw/pitch/roll), illumination, background uniformity, occlusion
(skin-tone coverage), expression neutrality, and gaze offset.
