# eel-abis-face-deident

Privacy-preserving face de-identification for the EEL ABIS pipeline.

Provides k-anonymity composite (Gross et al.), differential-privacy Gaussian
noise on embeddings (Dwork Gaussian mechanism), and blur/pixelation baselines.
All de-identified outputs are irreversible.

## References

- Sweeney (2002). k-anonymity: A model for protecting privacy. IJUFKS.
- Dwork & Roth (2014). The Algorithmic Foundations of Differential Privacy. FnTCS.
- Gross et al. (2009). Face de-identification. Springer.
