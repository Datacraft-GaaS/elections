# eel-portal-explainer (M68)

Referendum explainer site: plain-language explanations of all referendum questions in 11 languages with Kenya Sign Language (KSL) companion videos and text-to-speech audio.

## Locales

en, sw, ki, luo, kal, kam, guj, mer, mas, ksl-glossary, som

## Build

```bash
pnpm install
pnpm build
pnpm preview
```

## Accessibility

Target: WCAG 2.2 AAA (axe: 0 violations).

Requirements:

- All text meets 7:1 contrast ratio against background.
- Every image carries non-empty alt text.
- Every video links to a KSL companion or provides captions.
- Skip-to-main-content link on every page.
- Full keyboard navigability; no mouse-only interactions.
- Language switcher exposes `aria-current="page"` on the active locale.

## Accessibility tests

```bash
# Requires pnpm build + pnpm preview running on :4321
pnpm test
```

Playwright + axe-playwright assert 0 axe violations on the index page.

## TTS audio

Audio files are generated by `services/portal-svc/py/tts` and stored at configurable MinIO paths referenced via `tts_audio_url` in each content file.
