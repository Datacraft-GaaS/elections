# G16 — University Partnership MoU (CLOSED)
## 5 Partner Institutions
1. University of Nairobi (UON) — biometric research (NBIS validation)
2. Kenyatta University (KU) — cybersecurity (penetration testing, bug-bounty)
3. Strathmore University — data science (UEBA model training)
4. Jomo Kenyatta University of Technology (JKUAT) — hardware/M3 testing
5. Moi University — civic education (poll-worker training content)

## MoU Terms
- Duration: 2 years (renewable)
- In-kind contributions: research data, student interns, lab facilities
- Datacraft contributions: technical training, API access, equipment loans
- IP: jointly developed IP licensed CC-BY-4.0
- Confidentiality: standard NDA; election data access restricted to approved researchers
- Audit: M5 events for all API access by university credentials

## Signing
- Datacraft: CEO or CTO
- Each university: Vice-Chancellor
- Witnesses: IEBC representative + MoICT representative
