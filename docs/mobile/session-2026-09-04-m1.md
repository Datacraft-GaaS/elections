### B. M1.1 remediation — make mobile-bff compile and stop fabricating

Rewrite `services/field-mobile-svc/crates/mobile-bff/src/spec.rs` (and fix
`main.rs`) against the **real** platform APIs (§1):

1. Delete fabricated imports (`keycloak_token_exchange`,
   `spice_db_check_permission`, `hmac_sha256`, `OutboxClient`).
2. Router state: `BffState { pool, idempotency_store: Arc<IdempotencyStore>
   (TTL 72 h), spicedb: SpiceDbClient, jwks: JwksVerifier }`; construction is
   async where DDL is required; main.rs fixed (`Arc` import, single
   `with_state`, no double make-service).
3. Auth + idempotency via platform middleware: `require_jwt(jwks)` on all
   bearer routes; `idempotency_check(store)` layer on mutating routes — the
   header is read by the middleware, not minted per request.
4. Per-route SpiceDB checks through `SpiceDbClient::check` (role strings from
   the module tables); 403 `Problem::forbidden` on deny.
5. Handler honesty policy (never fabricate):
   - **Proxy to real client crates** where they exist: dispatch assignments →
     `dispatch-api`; voter lookup → `bvr-api`; observer access-pass →
     `training-api`. Upstream error → problem+json 502/503, never fake data.
   - **Postgres-backed** where the store is the point: `/config` (app config
     rows), idempotency replay cache, push-token registry, tamper/incident
     event rows (via `eel_outbox_rs::Outbox` envelope shape).
   - **Seams with explicit CI doubles** for external dependencies (plan §12
     risk convention): Play Integrity verdict via Google API and Keycloak code
     exchange behind trait interfaces; CI/dev builds use a double marked
     `attestation_tier=ci-software`. Doubles live in `#[cfg(test)]`/dev only —
     release builds get the real HTTP impls (reqwest).
   - Endpoints whose upstream genuinely does not exist yet (bvi-svc station
     status, rts forms sync) return a **503 problem+json "upstream not
     wired"** with the missing dependency named in `detail` — repo convention:
     print the missing prerequisite, never fail silently, never fake data.
6. Tests: unit tests per handler group using in-memory `IdempotencyStore`,
   axum `Router::new().with_state(...)` + `tower::ServiceExt::oneshot`, and an
   in-process axum mock for upstream HTTP (no new deps; reqwest already
   transitively available — confirm, else keep mocks at the trait seam).
   Idempotency test asserts same-key+same-body → cached 201, same-key+diff-body
   → 422. Auth test asserts 401 without token.
