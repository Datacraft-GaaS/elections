## 2. Conventions every WP follows

| Concern | Convention |
|---|---|
| Rust service layout | `services/<svc>/Cargo.toml` workspace; `crates/<svc>-api` (axum+utoipa+tonic), `crates/<svc>-domain`, `crates/<svc>-projections`, `crates/<svc>-worker`; `migrations/` (sqlx); `deploy/` (Kustomize base + overlays `primary`, `mirror`, `edge-*`); `tests/` (nextest + testcontainers); `loadtest/`; `docs/{README,EVENTS,THREAT-MODEL}.md`; `data_dictionary.yaml`; `TRACEABILITY.yaml` |
| Python tier | `services/<svc>/py/<pkg>/` (uv, FastAPI or worker), tabs, Pydantic v2 `extra='forbid'`, async throughout |
| Elixir tier | `services/<svc>/ex/<app>/` (Phoenix + LiveView + Ecto + Broadway + Oban; Rustler NIF to `iebc-crypto-rs`) |
| Django admin | `services/<svc>/django/<app>/` on `packages/iebc-web-py` |
| Astro | `services/<svc>/astro/<site>/` on `packages/iebc-web-astro` |
| Kit / mobile | `services/<svc>/apps/<app>/` Flutter on `packages/kit-sdk-flutter`; desktop `services/<svc>/apps/<app>-desktop/` Tauri 2 |
| Events | Only via `iebc-outbox-*`; schema in `packages/event-schemas/<ctx>/<agg>/<event>/v<n>.schema.json`; topic in `platform/kafka/topics/<topic>.yaml`; per `docs/EVENT-CONVENTIONS.md` |
| APIs | Spec-first in `packages/openapi-contracts/<ctx>/*.yaml`; spectral ruleset enforces ADR-0011 (tiers, RFC 9457, JSON+CBOR, signing headers, Idempotency-Key); clients regenerated by `just gen-clients` |
| Authz | `.zed` in `packages/authz-schema/<ctx>.zed` with golden tests per persona |
| Test tagging | Rust `#[trace("EC-DAT-01","FR-M02-007","AC-M02-03")]`, pytest `@pytest.mark.trace(...)`, ExUnit `@tag trace: [...]`, Flutter `testWidgets('... [EC-MOB-01]')`, Playwright `test('... @EC-SCL-01')` |
| IDs | UUIDv7 everywhere (`uuid7str()` shim) |
| Local SLA scaling | `loadtest/profiles/local.yaml` maps each Appendix-A number to a kind-profile budget (default 1/100); pre-prod runs 1x and 5x |
| Degradation | Every service implements normal / degraded / read-only via `iebc-resilience-*`; runbook `docs/runbooks/<svc>-degradation.md` |
| Gate evidence | Each wave gate produces `docs/audit/gate-G<n>.md` with links to CI runs, reports, signed by reviewers; gate record hashed to the transparency log once it exists (G2+) |

## 11. Risks and handling

| Risk | Handling |
|---|---|
| IEBC pre-bid answer changes a binding constraint (DR sites, retention, residency, signature suite) | Re-plan only the WPs that encode that constraint (0.4a contracts, 2.2 key roles, 3.1/3.3 signing, 5.9 DR); stack unchanged |
| Hardware SDKs (biometric sensors, RFID, HSM vendor) arrive late | Mock drivers + SoftHSM + RFID double from Wave 0; HIL benches added when hardware lands; parity tests gate swap-in |
| External MoUs (IPRS, CRS/NRB, telco, MCK, PPDT, eCourt) delayed | Doubles with contract tests are the build target; live adapter swap is config-only |
| Kotlin-for-kits resurfaces | Flutter path is RFP-aligned (legacy device reuse); shim + parity matrix documented |
| Context loss across agent sessions | Every WP section is self-contained; `TRACEABILITY.yaml` and gate records are the source of truth |
