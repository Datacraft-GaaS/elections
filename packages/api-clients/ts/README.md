# eel TypeScript API Client

Generated TypeScript type definitions and fetch clients for all eel OpenAPI contexts.

## Regenerate

From the repo root:

```sh
just gen-clients
```

Or from this directory:

```sh
./generate.sh --regen
```

## What the generated code contains

For each OpenAPI context (e.g. `elections`, `results`), two files are generated under `generated/<ctx>/`:

- `types.ts`: Full TypeScript types for all paths, parameters, request bodies, and response schemas, generated by `openapi-typescript`.
- `client.ts`: A thin typed fetch wrapper using `openapi-fetch` patterns.

## Usage

Install the runtime dependency once:

```sh
npm install openapi-fetch
```

Then import and use:

```ts
import { createEelClient } from "../api-clients/ts/generated/elections/client";

const client = createEelClient("https://api.eel.example.com");
const { data, error } = await client.GET("/elections/{id}", {
  params: { path: { id: "abc123" } },
});
```

## Notes

- The `generated/` directory is gitignored. Run `./generate.sh --regen` after pulling new OpenAPI specs.
- Requires `npx` (Node.js) for `openapi-typescript`. Prettier is applied post-generation if available.
- The generated `types.ts` is an ES module; use a bundler or Node.js with `"type": "module"`.
